Project Vision

  • Unified Operations: Real-time integration of telemetry, security, and fan engagement.
  • 3D Digital Twin: Live rendering of stadium layers (crowd density, accessible routes, eco grids).
  • AI Integration: Built-in multilingual GenAI concierge.
  • Glassmorphic UI: Premium aesthetic tailored for high-end operational dashboards.

System Architecture

Fully client-side, zero-build, ultra-portable setup.

graph TD; Main[index.html] --> UI[style.css]; Main --> Logic[app.js]; Logic --> 3D[three-stadium.js]; Logic --> AI[chat-assistant.js]; Logic --> Tel[telemetry-sim.js];

Core Modules Overview

  • three-stadium.js: Manages the 3D WebGL scene using Three.js (Cameras, Shaders, Particles).
  • chat-assistant.js: Parses user intents (transit, food, help) and provides localized automated responses.
  • telemetry-sim.js: Drives the live SVG gauges (Water, Solar, Waste).
  • incident-manager.js: The Operations Grid handling mock dispatches and HVAC triggers.

Dynamic Role Clearances

The dashboard adapts based on assigned roles:

  1. Fan View: Basic wayfinding & AI Chatbot.
  2. Volunteer View: Crowd density alerts & Queue tracking.
  3. VIP Command: Full HVAC access, incident dispatching, raw telemetry logs.
